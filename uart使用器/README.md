# UART 收发与数据帧解析

Windows 桌面串口工具，支持收发、数据帧解析与波形分析。双击 `UART串口助手.exe` 启动；源码修改后可运行 `build.bat` 重新打包。

## 代码结构

- `main.py`：程序入口、主窗口和页面切换。
- `serial_io.py`：串口扫描、连接、接收、发送及日志显示。
- `frame_send.py`：数据帧发送界面、十进制字段到字节的转换。
- `frame_parse.py`：数据帧解析界面、字段定义、配置文件与持续解析。
- `waveform.py`：波形窗口、绘制与交互。
- `make_icon.py`：生成应用图标，仅用于构建。

各功能模块以 mixin 方式组成 `main.App`，共享窗口状态。修改涉及跨页面的状态时，应同时查看相关模块。
